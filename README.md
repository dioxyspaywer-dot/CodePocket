# CodePocket

## Obtenir l'APK
1. Crée un dépôt GitHub et envoie-y tous ces fichiers (garde le dossier .github).
2. Onglet Actions : le workflow "Build APK" se lance à chaque push.
3. Télécharge l'artefact CodePocket-apk et installe app-debug.apk.

## Utiliser l'app
1. Onglet GitHub : colle le token, l'URL du dépôt, la branche. Touche "Tester le token".
2. Touche "Pull" : les fichiers du dépôt arrivent dans l'explorateur.
3. Ouvre un fichier et modifie-le (sauvegarde automatique sur le téléphone).
4. Onglet Git : écris un message, touche "Valider" (commit local).
5. Onglet GitHub : touche "Push" pour envoyer à GitHub.
Ordre : Pull, modifier, Commit, Push.
Si GitHub a changé depuis ton dernier Pull, l'app te prévient à l'ouverture.
